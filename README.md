# GeriAgenda — projeto completo
Protótipo front-end de agendamento de consultas geriátricas.

## Executar
Abra a pasta no VS Code e abra `index.html` no navegador. Live Server não é obrigatório.

## Login de demonstração
E-mail: `maria@email.com`
Senha: `123456`

## Fluxo
Login → Datas e horários → escolher horário → Confirmar → Sucesso → Meus agendamentos.

## Telas
Login, cadastro, datas/horários, confirmação, sucesso, meus agendamentos, painel do responsável, pacientes, gerenciamento de datas, gerenciamento de horários e relatórios.

Os dados do protótipo ficam no localStorage do navegador. Não há banco de dados neste protótipo.
